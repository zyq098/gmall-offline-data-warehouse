# 电商离线数据仓库项目

基于尚硅谷电商数仓V6.0的离线数仓实战项目，完整实现ODS→DWD→DWS→ADS四层数据仓库架构，包含数据采集、ETL清洗、维度建模、指标计算和可视化大屏全流程。

## 技术栈

| 类别 | 技术 |
|------|------|
| 数据采集 | DataX、Maxwell、Kafka、Flume |
| 存储计算 | Hadoop、Hive、Spark |
| 任务调度 | DolphinScheduler |
| 数据模型 | 维度建模（星型模型、维度退化） |
| 可视化 | ECharts、HTML+CSS大屏 |
| 开发语言 | Hive SQL、Python |

## 项目架构

```
业务数据(MySQL)
    ↓
ODS层（原始数据层）—— DataX/Maxwell/Kafka/Flume采集
    ↓
DWD层（明细数据层）—— 清洗、过滤、维度退化、拉链表
    ↓
DWS层（汇总数据层）—— 按用户/商品/品牌粒度轻度聚合（1d/nd/td）
    ↓
ADS层（应用数据层）—— 报表指标、多维统计、用户留存
    ↓
可视化大屏（ECharts）
```

## 核心知识点

- **ODS层**：全量表/增量表区分、分区策略、DataX同步
- **DWD层**：事实表类型（事务/周期快照/累计快照）、维度退化、拉链表设计、数据清洗
- **DWS层**：1d/nd/td三种汇总粒度、用户留存计算、连续登录用户窗口函数、累计快照表增量更新
- **ADS层**：多周期union炸裂、指标去重口径、报表宽表设计
- **可视化**：ECharts地图、visualMap颜色映射、深色科技风大屏布局

## 项目亮点

1. 完整实现数仓四层架构，从数据采集到报表输出全链路打通
2. 深入理解维度建模核心概念：事实表、维度表、维度退化、拉链表
3. 掌握DWS层nd滚动窗口表和td累计快照表的设计与增量更新策略
4. 用窗口函数（row_number/lead/lag）解决连续登录、留存率等经典指标问题
5. 基于真实业务场景设计ADS层报表指标，并用ECharts实现可视化大屏

## 学习收获

- 理解数据仓库分层的意义和每层的职责边界
- 掌握Hive SQL复杂查询、窗口函数、UDTF炸裂等高级用法
- 学会从业务需求反推数据模型设计，而不是只会写SQL
- 了解数据开发全流程：需求分析→模型设计→ETL开发→数据质量→报表输出
